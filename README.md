# YoloToJson v1.2.0.0

YOLO 标注格式转 LabelMe JSON 格式的桌面工具，提供图形化交互界面，支持单文件与批量转换，默认中文界面，可切换英文。

## 功能概览

| 功能 | 说明 |
|------|------|
| 单文件转换 | 选择一个 `.txt` 文件 + 对应图像，输出一个 `.json` 文件 |
| 批量转换 | 选择一个包含 `.txt` 文件的文件夹，批量转换为 `.json` |
| 类别名称映射 | 编辑 Class ID → 类别名称的对应关系；可一键生成默认类别直接使用（无需修改），也可双击手动修改；支持 CSV 与 YOLO classes.txt 导入/导出 |
| 输出配置 | 指定 JSON 输出目录，支持文件冲突策略（覆盖/跳过） |
| 打开输出目录 | 转换完成后一键在资源管理器中打开 JSON 输出文件夹 |
| 取消转换 | 批量转换过程中可随时中止（逐文件检查取消标志，立即停止并保留已完成的结果） |
| 中英切换 | 菜单栏 语言 → 中文 / English，实时切换界面语言 |
| 版本信息 | 窗口标题栏、关于对话框、.exe 文件属性中显示 `1.2.0.0` |
| 设置持久化 | 上次使用的路径、类别名称、窗口大小等自动保存为 `config.ini`（exe 模式保存在 exe 同目录） |
| 图像裁切工具 | 菜单 工具 → 图像裁切工具：浏览图像、拖拽矩形裁切、批量应用（详见下文） |
| YOLO 标注工具 | 菜单 工具 → YOLO 标注工具：画框/改框/删框、类别管理、逐图保存 YOLO txt（详见下文） |

## 图像裁切工具

主界面菜单 **工具 → 图像裁切工具** 打开独立窗口：

- **浏览**：打开图像文件夹（或按住 Ctrl 多选图像），缩放适配画布，上一张/下一张/跳转（支持 ← → 方向键）
- **单张裁切**：在图像上按住左键拖拽绘制矩形（实时显示 `x,y 宽×高`），松开后弹出保存确认
  - 保存名称：`img001.jpg → img001_cr.jpg`；默认保存到原图所在文件夹，可点 **更改文件夹...** 换目标目录
  - 勾选 **默认保存（免确认）** 后，松开鼠标立即保存并自动跳到下一张
  - 输出位置可全局切换：原图所在文件夹（默认）/ 指定目录
- **批量应用**：画好矩形后
  - **应用到所有图像**：一键把当前裁切框应用到文件夹内全部图像
  - **应用到选中图像...**：二级对话框多选图像（全选/全不选/反选）后一键执行
  - 裁切框按归一化坐标存储，不同尺寸图像按比例适配；批量在后台线程执行，带进度条、可取消、逐文件日志
  - 已存在文件策略：覆盖 / 跳过（与转换器共用 `config.ini` 中的冲突策略）

裁切框数据结构（`Region`，归一化坐标）与浏览基类（`viewer_base.py`）预留了 `label` 字段与叠加图形扩展点，供后续 YOLO 标注模块复用。

## YOLO 标注工具

主界面菜单 **工具 → YOLO 标注工具** 打开独立窗口，用于直接编辑 YOLO 检测标注：

- **浏览**：打开图像文件夹；自动加载同目录 `classes.txt`（无则使用主界面 config.ini 的类别映射）；每张图自动加载同名 `.txt` 已有标注
- **画布操作**：拖拽空白处=新建框（用"当前类别"）；点框=选中；拖动=移动；八点手柄=缩放；右键框=改类别/删除；滚轮=以鼠标为中心缩放；中键拖拽=平移；双击=复位适配窗口
- **类别**：下拉框选择当前类别，数字键 `0-9` 快捷切换；选中框后按数字键直接改该框类别；**编辑类别...** 打开完整类别管理（添加/删除/导入导出 CSV 与 classes.txt）
- **保存**：`Ctrl+S` 或按钮，写入图片同名 `.txt`（YOLO 归一化格式，六位小数）；类别有改动时同步写 `classes.txt`
- **自动保存**：默认开启——切换图像时自动保存修改；关闭后切换时会询问（保存/放弃/取消）
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`，每图独立快照栈（上限 100 步），覆盖绘制/移动/缩放/删除/改类
- **复制上一张标注**：把上一张图的框按归一化坐标复制到当前图（适用于相似帧）
- **标注列表**：右侧面板实时列出所有框（序号/类别/坐标），与画布双向联动选中

## 系统要求

- Windows 10 / 11
- 64 位操作系统
- 独立 `.exe` 无需安装 Python

## 快速开始

### 方式一：运行 .exe（推荐）

直接双击 `dist/YoloToJson.exe` 启动。

右键 `.exe` → 属性 → 详细信息，可查看版本号 `1.2.0.0`。

### 方式二：Python 源码运行

```bash
pip install Pillow
python main.py
```

## 使用流程

1. 选择模式：单文件 或 批量文件夹
2. 选择 YOLO `.txt` 文件（或文件夹）
3. 选择对应的图像文件夹
4. 编辑类别名称映射表（Class ID → 类别名称）
5. 指定 JSON 输出目录
6. 点击 **开始转换**
7. 转换完成后点击 **打开输出目录** 查看结果

## 标注格式

### YOLO 格式（输入）

每行一个目标，空格分隔的归一化坐标：

```
class_id x_center y_center width height
```

所有坐标值为归一化值（0~1），相对于图像宽度和高度。

示例（`test.txt`）：
```
0 0.5 0.5 0.3 0.4
1 0.2 0.3 0.1 0.15
```

### LabelMe JSON 格式（输出）

```json
{
  "version": "4.5.6",
  "flags": {},
  "shapes": [
    {
      "label": "defect",
      "points": [[224, 144], [416, 144], [416, 336], [224, 336]],
      "group_id": null,
      "shape_type": "rectangle",
      "flags": {}
    }
  ],
  "imagePath": "test.jpg",
  "imageData": null,
  "imageHeight": 480,
  "imageWidth": 640
}
```

## 支持的图像格式

`.jpg` `.jpeg` `.png` `.bmp` `.tiff` `.tif`

图像文件名必须与 `.txt` 文件名一致，扩展名大小写不限（`.jpg`、`.JPG`、`.Jpg` 均可匹配）。例如 `image001.txt` 会匹配 `image001.jpg`、`image001.PNG`、`image001.tif` 等。

## 项目结构

```
Yolo_to_json/
├── main.py                # GUI 主程序 (tkinter), VERSION 常量
├── yolo_to_json.py         # 核心转换逻辑 (YOLO → LabelMe JSON)
├── converter_worker.py     # 后台线程工作器 (非阻塞转换)
├── settings_manager.py     # 配置持久化 (config.ini, 默认类别 defect)
├── lang.py                 # 中英双语 i18n 模块 (>100 条翻译)
├── image_cropper.py        # 裁切核心逻辑 (Region / 单张 / 批量裁切)
├── viewer_base.py          # 图像浏览器基类 (缩放/导航/坐标换算, 标注扩展点)
├── cropper_window.py       # 裁切工具窗口 (拖拽裁切 / 保存确认 / 批量应用)
├── ui_theme.py             # 共享颜色/字体常量
├── class_manager.py        # 类别映射表格组件 (转换器/标注器共用)
├── yolo_annotation.py      # YOLO 标注核心逻辑 (txt 解析/写入, classes.txt)
├── annotator_window.py     # YOLO 标注窗口 (完整框编辑 / 撤销 / 自动保存)
├── build.spec              # PyInstaller 打包配置 (含版本信息)
├── version_info.txt        # Windows VSVersionInfo (1.2.0.0)
├── requirements.txt        # Python 依赖 (Pillow, pyinstaller)
├── .vscode/                # VS Code 调试配置
│   ├── launch.json         # 4 种调试模式 (F5 启动)
│   └── settings.json       # Python 解释器路径
├── dist/
│   └── YoloToJson.exe      # 独立可执行文件 (约 30 MB)
└── README.md
```

## 构建 .exe

```bash
pip install Pillow pyinstaller
python -m PyInstaller build.spec --noconfirm

```
