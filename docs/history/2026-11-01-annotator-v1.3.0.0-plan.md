# YOLO 标注工具增强计划（master_cr 分支，v1.3.0.0）

## Context
标注工具（v1.2.0.0）日常使用后提出 6 项增强：右侧加图像列表带标注状态勾选、键盘快速导航、图像删除（回收站式移出）、未标注跳转、列表筛选，以及修复拖动框位置跑飞的 bug。已确认键位：A=上一张、D=下一张、Shift+D=删除图像、Ctrl+Shift+A/D=检查上/下一张未标注。

## 1. Bug 修复：拖动框位置跑飞（需求6，优先修）
`annotator_window.py` `on_draw_move` move 分支每次读取**已被上一帧修改的框**再叠加相对手势起点的总位移 → 位移逐帧累加。修复：手势开始时快照框的原始像素位置 `_move_orig`，move 时 `原始位置 + 总位移`（含边界钳制）。补连续多次 move 的回归测试（此前测试只有单次 move，未暴露）。

## 2. 右侧面板改造（需求1）
右栏改为上下两区（grid weight 1:3，box 列表占 1/4 高度）：
- **上：标注列表**（现有 Treeview，联动逻辑不变）
- **下：图像列表面板**（新 LabelFrame）：
  - 顶部筛选行（见 §5）
  - Treeview 两列：`勾选 | 文件名`；**已标注**（同名 .txt 存在且解析出 ≥1 个框）显示 ✓，未标注为空
  - 按文件名排序（加载顺序本已排序）；当前图像高亮并跟随滚动
  - 点击行 → 经未保存检查后跳转该图

## 3. 导航与删除（需求2、3、4）
- **A/D**：`<KeyPress-a/A>` = 上一张、`<KeyPress-d>` = 下一张（与 ←/→ 并存；tk 取最具体绑定，Ctrl+Shift+D 不会误触 Shift+D）
- **Shift+D 删除**（`<KeyPress-D>`）：
  - 图像 + 同名 .txt（若存在）移动到 `<图像目录>/../_delete/`（不存在则创建，同名覆盖 os.replace 语义）
  - 首次弹自定义对话框：「是否删除当前图像，以及对应标签」是/否 + ☑默认按此选择不再询问；勾选后按所选答案持久化（settings 新增 `delete_remember` / `delete_default_yes`），此后静默执行；记住"否"则后续 Shift+D 无操作（重置入口：删 config.ini 对应键，README 注明）
  - 删除后从文件列表移除，**停留在原索引（即下一张）**；删的是最后一张则停到前一张；列表空则清空画布；同步更新标注缓存与图像列表
  - viewer_base.py 新增 `remove_path(path)`：列表删除 + 索引钳制 + 重载
- **Ctrl+Shift+A / Ctrl+Shift+D 检查未标注**：从当前位置向前/向后在全量列表中环绕搜索第一个未标注图像并跳转；没有未标注时状态栏提示

## 4. 标注状态缓存
打开文件夹时解析全部 txt 一次，建 `路径 → boxes` 缓存（已标注 = len>0，标注列表勾选、未标注跳转、标签筛选共用）；保存/删除时更新对应项；删除图像时移除。

## 5. 筛选（需求5）
图像列表面板顶部两个下拉框：
- **状态**：所有图像 / 已标注 / 未标注（默认所有）
- **标签**：所有标签 + 当前类别表各项（按 class id）
- 筛选同时作用于：图像列表显示 **和** 上一张/下一张/A/D/←/→ 导航（在筛选子集内、按全量顺序循环）；Ctrl+Shift+A/D 未标注检查始终在全量列表搜索（语义专用）；当前图像不在筛选集内时保持显示，导航从其在全量顺序中的位置继续
- 列表面板标题显示「图像列表 (12/25)」

## 6. 文件改动
- `annotator_window.py`：右栏布局、图像列表+筛选、删除流程（含确认对话框）、未标注跳转、键位绑定、move bug 修复、状态缓存
- `viewer_base.py`：+`remove_path()`
- `settings_manager.py`：+`delete_remember`、`delete_default_yes`
- `lang.py`：约 25 条新文案；`version_info.txt` / `README.md`：→ 1.3.0.0（build.spec 模块清单不变）
